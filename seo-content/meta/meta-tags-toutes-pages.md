## 💡 Règles d'implémentation

### Format Next.js App Router (à copier-coller)

```typescript
// Dans chaque app/[page]/page.tsx
import type { Metadata } from 'next'

export const metadata: Metadata = {
  title: '...',          // max 60 caractères
  description: '...',   // max 155 caractères
  alternates: {
    canonical: 'https://brainlo.ai/[slug]',
  },
  openGraph: {
    title: '...',
    description: '...',
    url: 'https://brainlo.ai/[slug]',
    images: [{ url: '/og-[page].png', width: 1200, height: 630 }],
  },
}
```

### Règles de rédaction SEO

| Élément | Max caractères | Règle |
|---|---|---|
| `<title>` | 60 | Mot-clé principal en tête |
| `<description>` | 155 | Inclure CTA + différenciation |
| OG title | 70 | Plus accrocheur que le title |
| OG description | 200 | Plus marketing que la meta desc |
